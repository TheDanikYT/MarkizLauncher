Возможности

Один лаунчер вместо десяти вкладок

Всё, что обычно собирают по форумам и дискордам, лежит в одном приложении — от установки версии до поиска компании на вечер.

Сборки в один клик

Создайте профиль под нужную версию и загрузчик, добавьте моды — лаунчер сам разложит файлы, выставит память и подберёт аргументы запуска. Отдельные папки игр не нужны.

  • Fabric
  • Forge
  • NeoForge
  • Quilt
  • Ванилла

Каталог модов

Поиск по Modrinth прямо в лаунчере: описание, версии, зависимости. Ставится без похода в браузер и распаковки архивов вручную.

Гардероб

Скины, плащи и косметика — с 3D-предпросмотром. Модель крутится прямо в окне, менять её можно не выходя из лаунчера.

Друзья и чат

Список друзей со статусом «в игре», личные сообщения и общий чат. Видно, кто на каком сервере — присоединиться можно в пару секунд.

Свой сервер

Панель хостинга внутри лаунчера: запуск, настройки и моды без консоли и SSH. Подходит, чтобы позвать друзей на выходные.

Ничего не нужно доустанавливать

Лаунчер сам скачает подходящую версию Java под выбранную сборку, сам обновится до новой версии и сам проверит целостность файлов игры. Антивирус и «Ява не найдена» перестают быть частью вечера.

Интерфейс

Тёмное окно, знакомые кнопки

Экраны на React, ядро на Rust. Окно открывается быстро, анимации не мешают нажимать «Играть». Всё, что нужно новичку — на первом экране, всё, что нужно опытному — в двух кликах.

  • Лобби с быстрым запуском последней сборки
  • Полки «Мои сборки» и «Каталог» рядом
  • Настройки памяти и аргументов — без редактирования json
  • 21 язык интерфейса, включая RTL

Безопасность

Почему этому можно доверять

Лаунчер держит вход в аккаунт, файлы игры и сетевые запросы — единственный честный ответ на «что он делает с моим аккаунтом» это дать прочитать код целиком.

01

Код открыт

Вся логика — на GitHub под GPL-3.0. Можно сверить любую строку, собрать свою версию и посмотреть, куда уходят запросы.

02

Пароль не виден

Вход с лицензией идёт через официальное окно Microsoft. Лаунчер получает токен, а не пароль, и не хранит его в открытом виде.

03

Только официальные сборки

Качайте файлы из раздела Releases этого репозитория. Сторонние «пересборки» с файлопомоек никто не проверял.

Вопросы

Коротко о главном

Это бесплатно?

Да. Без рекламы и без постороннего софта в установщике.

Нужен купленный Minecraft?

Нет, можно играть по нику. С лицензией — вход через официальное окно Microsoft, пароль лаунчер не видит.

Java ставить нужно?

Нет, лаунчер скачает подходящую версию сам — отдельно для каждой сборки.

Антивирус ругается — что делать?

Скачивайте только из раздела релизов этого репозитория. Неподписанные сборки часто попадают в ложные срабатывания — проверьте файл на VirusTotal и сравните хеш с указанным в релизе.

Что-то не работает

Заведите issue в репозитории и приложите logs/launcher-latest.log из папки сборки — по логу видно почти любую причину.

Это тот же Millida Launcher?

Markiz — форк Millida Launcher: тот же движок и интерфейс, своё имя, свои иконки и своя сборка. Исходный проект под GPL-3.0, поэтому форк легален, но бренд и сервисы оригинала под лицензию не попадают.
